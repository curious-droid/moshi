Same conversation, different models

None of these conversations were in the training data. Each one plays the script up to the moment being tested and then lets Moshi respond on its own. The buttons switch between base Moshi and the models trained on 1, 10, 89 and 100 hours of data. The timeline shows who is speaking, the shaded stretch where Moshi was asked to wait, and in red any speech from Moshi during that wait. The audio mixes both sides into one track.

Scoring a test conversation

    What generalizes

    Each row is a test set held out from training in a different way, for example new scripts, new wording of the request, speakers the model never heard, or a phone call, which never appears in training. n is the number of test conversations with a wait. Hover over a cell for its 95% interval.

    Normal conversation

    Waiting when asked while still answering normally

    Each row compares base Moshi with the 100 h model. The model answers contrast twins (conversations that start like a hold but never ask Moshi to wait) and ordinary questions a bit more often than base Moshi. It also stops when the user interrupts it. The cost is that it stops more often at a listener's "mm-hmm," which is one of the limits below.
